Bulk Import

Load sections, teachers and subjects from a university's published timetable page or a CSV instead of typing them. Manual entry on the Sections, Subjects and Faculty pages still works.

1. Where is the timetable?

The server downloads the page and reads its weekly grid and teacher table. If the site blocks downloads, open the page, press Ctrl+S, and use "Upload a file".

One row per subject taught to one section. type = lecture or practical; periods = per week (practical: sessions); co_teachers separated by ; ; joint_group (optional) = same word for sections that attend the same lecture together. Download the template
